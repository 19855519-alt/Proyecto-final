
# Pupusas 3x1 🇸🇻

Sitio web para presentar el emprendimiento Pupusas 3x1, mostrar el menú y las promociones, y recibir consultas de los visitantes.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Vercel Functions
- Discord Webhooks
- GitHub

## Funciones de la página

- Inicio y presentación del emprendimiento.
- Menú de pupusas con precios.
- Sección de promociones.
- Espacios para agregar fotografías propias.
- Enlace al perfil de Instagram.
- Formulario de contacto conectado con Discord.
- Diseño adaptable a computadoras, tabletas y celulares.

## Instalación

1. Descargá o cloná el repositorio.
2. Abrí la carpeta en Visual Studio Code.
3. Agregá las imágenes dentro de la carpeta `imagenes`.
4. Configurá la variable `DISCORD_WEBHOOK_URL` en Vercel.
5. Publicá el proyecto en Vercel.

## Imágenes

Las fotografías se guardan en la carpeta `imagenes`. Los nombres deben coincidir con los utilizados en `index.html`.
